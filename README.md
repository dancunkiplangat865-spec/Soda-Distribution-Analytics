# Soda Distribution Analytics

## Project Overview

This project focuses on analyzing the operations of a soda distribution business using Microsoft Excel.

The objective is to organize operational data, analyze business performance, and generate insights that can support better decision-making.

## Business Areas Covered

- Sales Performance Analysis
- Inventory and Stock Management
- Product and Supplier Analysis
- Customer and Shop Analysis
- Vehicle and Delivery Operations
- Stock Receipts and Adjustments
- Payment Analysis

## Tools Used

- Microsoft Excel
- Power Query
- PivotTables
- Excel Formulas
- Data Visualization

## Project Components

1. Data preparation and cleaning
2. Operational data analysis
3. KPI development
4. Dashboard development
5. Business insights and recommendations
